Internal tool for Montessori School, A-Camp — fill this in, click "Generate files", then upload what it gives you to GitHub. This page never sends anything anywhere by itself.

2. Event details

Each paragraph is a separate block of text on the page. Add as many as you need.

3. Photos

Photos are automatically resized and compressed for the web — upload the original file straight from your camera or phone, no need to edit it first.

4. Videos (optional)

Paste a normal YouTube link (youtube.com/watch?v=... or youtu.be/...). If a video shows blank/refuses to play once it's live, come back and tick "opens on YouTube instead" for it.

5. Publish directly to GitHub

Commits the new photos and the updated data file straight to the main branch — no manual upload needed.
